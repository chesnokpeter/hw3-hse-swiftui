# ДЗ. Каталог фильмов

Чесноков Пётр Ильич, БПИ261

Приложение на SwiftUI для iOS 17 и новее. Можно добавлять фильмы, менять название, год и жанр, отмечать просмотренные и ставить оценку от 1 до 5. Фильм удаляется свайпом влево. Каталог сохраняется в SwiftData между запусками. Для Preview используется отдельное хранилище в памяти с четырьмя фильмами.

### Дополнительные задания

- Поиск по названию и жанру работает вместе с фильтром по статусу. Отбор выполняет SwiftData через `#Predicate`.
- Список можно сортировать по дате добавления, названию, году и оценке. Над списком показаны общее число фильмов, число просмотренных и средняя оценка по фильмам с оценкой.
- Один `Genre` может быть связан с несколькими фильмами. Правило `.nullify` при удалении жанра очищает связь, а фильмы остаются в каталоге с подписью «Без жанра».
- Сердце над списком включает фильтр избранного. Через меню можно выбрать несколько фильмов и разом отметить их просмотренными.

Откройте `MovieCatalog.xcodeproj`, выберите симулятор iPhone и нажмите `⌘R`.
